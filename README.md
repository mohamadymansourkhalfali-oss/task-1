1. ليه الناتج طلع $30.00؟
عشان X + Y بيساوي 30، والـ :C بتخلي الرقم يظهر على شكل فلوس، فبتضيف علامة الدولار ورقمين بعد العلامة العشرية.

2. إيه فايدة الـ :C؟
بتستخدمها لما نكون عايزين نعرض رقم على إنه مبلغ فلوس، وبتخلي شكل الرقم أوضح وأسهل في القراءة.

3. اكتب مثال تاني باستخدام Format مختلف:

int X = 1000;
int Y = 2500;

Console.WriteLine($"Equation: {X} + {Y} = {X + Y:N2}");

الناتج:

Equation: 1000 + 2500 = 3,500.00

هنا استخدمنا :N2، ودي بتخلي الرقم فيه فاصلة للآلاف ورقمين بعد العلامة العشرية.
